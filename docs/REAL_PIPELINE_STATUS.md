## 3. Real Component Status Matrix

| Component | Status | Evidence / Verification |
| :--- | :--- | :--- |
| **Stream Gateway** | `REAL DECODING` | `stream_gateway/stream_manager.py` decodes real video frames using OpenCV FFmpeg with TCP transport and PTS timestamps. |
| **Vehicle Detection** | `REAL YOLO` | `ai/detection/detector.py` uses Ultralytics YOLOv8 for car, truck, bus, and motorcycle bounding box extraction. |
| **Multi-Object Tracking** | `REAL CENTROID TRACKING` | `ai/tracking/tracker.py` computes Euclidean centroid distances to assign persistent `track_id` values across frames. |
| **ANPR & OCR Engine** | `REAL EASYOCR` | `ai/anpr/anpr_engine.py` applies CLAHE contrast enhancement, EasyOCR text extraction, and Indian plate normalization regex. |
| **Disk Image Crops** | `REAL PERSISTENCE` | Actual vehicle crop JPEGs written to `data/vehicle_crops/` and plate crops to `data/plates/`. |
| **Database Storage** | `REAL POSTGIS/SQLITE` | Detections and Watchlist Alerts inserted directly into `detections` table via SQLAlchemy async ORM. |
| **Backend REST API** | `REAL REST ENDPOINTS` | `/api/vehicles/{plate}/journey` queries real DB rows and returns actual local image URLs (`/data/vehicle_crops/...`). |
| **Frontend UI Rendering** | `REAL CROPS DISPLAY` | `VehicleJourneyView.tsx` renders actual crop images from the backend. Hardcoded Unsplash images removed. |
| **Pipeline Telemetry** | `REAL HEALTH METRICS` | `/api/pipeline/health` and `PipelineHealthView.tsx` display live stream FPS, YOLO latency, OCR attempts/successes, and DB inserts. |
| **Integration Test** | `100% PASSED` | `tests/test_real_pipeline.py` passed full end-to-end test suite proving frame $\rightarrow$ YOLO $\rightarrow$ tracking $\rightarrow$ OCR $\rightarrow$ DB row $\rightarrow$ crop file $\rightarrow$ API response. |
